# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This is a GitHub **profile README** repository (`ichrakhamdi/ichrakhamdi`). GitHub renders `README.md` at the top of https://github.com/ichrakhamdi. Pushing to `main` publishes changes immediately.

## Graphics

Every SVG in `assets/` is generated by `scripts/make_svgs.py`. Don't hand-edit them. Change the data in the script (`EXPERIENCE`, `EDUCATION`, `PROJECTS`, the `stack()` rows) and regenerate:

```sh
python3 scripts/make_svgs.py            # writes into assets/
```

- `hero.svg` is the only graphic with its own (navy) background. The tech stack, experience, education and project graphics have **transparent backgrounds** and come in `-light.svg` / `-dark.svg` pairs. The README picks one with `<picture><source media="(prefers-color-scheme: dark)" ...>`, which GitHub maps to the viewer's theme. Colors live in `THEMES`.
- The tech-stack logos are devicon SVGs vendored in `scripts/icons/` and embedded as base64 data URIs, because GitHub's image proxy won't load external images inside an SVG. They sit on light tiles so dark logos (Kafka) stay visible in dark mode.
- GitHub shows the README column about 830px wide, so a 1200px graphic is scaled to ~0.7 and a 49%-width project card to ~0.7 of 580px. Keep body text at 19px or more inside the SVGs so it stays readable. Text is wrapped by hand.
- To check one, render it with headless Chrome: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars --window-size=1200,560 --screenshot=out.png file://$PWD/assets/stack-dark.svg`. Check both themes.

## Content rules

- The profile targets **ML engineering, data science and code/model evaluation roles** (for example, data-annotation and evaluation contracts that want Python, SQL, code review and agent-evaluation experience). Lead with ML engineering. The PhD comes second.
- **The PhD research is unpublished and confidential.** Describe it only as "autonomous AI agents for the cyberdefense of industrial cyber-physical systems", tagged with reinforcement learning and industrial cyber-physical systems (the hero banner shows both as PhD chips). Don't add method details, architecture diagrams or pipeline descriptions, and don't mention hierarchical RL.
- No emoji anywhere.
- Experience, awards and education come from the owner's CV. Every project description must match what the linked repo contains. Don't invent metrics or years of experience.
- The only contact email to publish is `ichrak.hamdi@ensi-uma.tn` (header and Connect badges). Never publish the phone number or the ulaval address.
- Section order: hero + one row of contact badges → About me (one sentence + Now/Before/Teaching bullets) → Tech Stack → Experience (newest first) → Featured Projects (clickable cards, 2 per row at `width="49%"`, plus a `<details>` table) → Education (cards) → Awards & Recognition → contact footer. Body text is left-aligned. Only the hero and the badge rows are centered.
- The LinkedIn URL appears twice (header and Connect section). Update both.
