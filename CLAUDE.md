# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This is a GitHub **profile README** repository (`ichrakhamdi/ichrakhamdi`). GitHub renders `README.md` at the top of https://github.com/ichrakhamdi. Pushing to `main` publishes changes immediately.

## Graphics

Every SVG in `assets/` is generated by `scripts/make_svgs.py`: the hero banner, highlights strip, "What I do" logo grid, experience timeline and project cards. The logo grid embeds the devicon logos vendored in `scripts/icons/` as base64 data URIs, because GitHub's image proxy won't load external images inside an SVG. Don't hand-edit them. Change the data in the script and regenerate:

```sh
python3 scripts/make_svgs.py            # writes into assets/
```

- Card text is wrapped by hand: each description is a list of lines of about 48 characters. Chip widths come from a fixed char-width estimate (`MONO_CW`), so check the render after changing a label.
- GitHub serves the SVGs through its image proxy, so they can't load external fonts or scripts. Animation is limited to CSS keyframes and SMIL. Each SVG draws its own dark background so it reads the same in light and dark themes.
- To check one, render it: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars --window-size=1200,530 --screenshot=out.png file://$PWD/assets/expertise.svg`. Match the window size to the SVG's height.
